# 🥗 NutriFit App - Sistema Completo de Alimentación y Entrenamiento

## 🚀 Estado Actual: COMPLETAMENTE FUNCIONAL

### ✅ Funcionalidades Implementadas

#### 🔐 **Sistema de Autenticación**
- Registro único por teléfono chileno (+56)
- Login simplificado
- Onboarding completo de 5 pasos
- Rutas protegidas

#### 📊 **Dashboard Personalizado**  
- Datos reales del usuario autenticado
- Cálculo automático de métricas (IMC, TMB, GET)
- Macronutrientes personalizados
- Navegación funcional

#### 🍽️ **Sistema de Recetas**
- Catálogo interactivo con filtros avanzados
- Búsqueda por ingredientes y categorías
- Información nutricional detallada
- Tiempo de preparación y tags

#### 🗓️ **Generador de Planes Alimentarios**
- Generación automática personalizada
- Respeta días de ayuno intermitente  
- Cálculo de calorías objetivo
- Tracking de adherencia
- Planes de 1 día a 1 mes

#### 👤 **Perfil Editable**
- Edición in-line de información personal
- Datos de salud y preferencias
- Horarios y rutinas personalizables
- Actualización en tiempo real

#### 🎨 **Interfaz Moderna**
- Tailwind CSS completamente configurado
- Componentes responsivos
- Iconos Heroicons integrados
- Estados interactivos y animaciones

## 🛠️ Tecnologías

- **Frontend:** React + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Estado:** Zustand
- **Routing:** React Router
- **Iconos:** Heroicons
- **Formularios:** React Hook Form (preparado)

## 🏃‍♂️ Cómo Ejecutar

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`

1. **Registro** → Teléfono + datos personales

4. **Recetas** → Explorar y filtrar
5. **Planes** → Generar planes personalizados
6. **Perfil** → Editar configuración
